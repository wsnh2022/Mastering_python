For a **generic multi-search automation**, remove the hardcoded article and prompt. Use a single placeholder that your Python/Playwright code URL-encodes before opening each site.

```text
# ChatGPT
https://chatgpt.com/?q={URL_ENCODED_PROMPT}

# Perplexity
https://www.perplexity.ai/search/new?q={URL_ENCODED_PROMPT}

# Google AI Mode
https://www.google.com/search?udm=50&q={URL_ENCODED_PROMPT}

# Claude
https://claude.ai/new?q={URL_ENCODED_PROMPT}

# Grok
https://x.com/i/grok?text={URL_ENCODED_PROMPT}
```

## If your prompt includes a URL

Instead of embedding the URL into each template, make your prompt dynamic.

Example prompt:

```text
Analyze and summarize {URL}.
Focus on:
- Main ideas
- Key insights
- Practical applications
- Advantages and disadvantages
- Actionable recommendations
```

After URL encoding, it becomes the value for `{URL_ENCODED_PROMPT}` and works with all five services.

---
## Python example

```python
from urllib.parse import quote

prompt = """
Analyze and summarize https://example.com

Focus on:
- Main ideas
- Key insights
- Practical applications
- Pros and cons
- Actionable recommendations
"""

encoded = quote(prompt)

urls = {
    "ChatGPT": f"https://chatgpt.com/?q={encoded}",
    "Perplexity": f"https://www.perplexity.ai/search/new?q={encoded}",
    "Google AI": f"https://www.google.com/search?udm=50&q={encoded}",
    "Claude": f"https://claude.ai/new?q={encoded}",
    "Grok": f"https://x.com/i/grok?text={encoded}",
}

for name, url in urls.items():
    print(name, url)
```
